* Repository Structure
- Any top-level directory whose name does not begin with "." or "_" is
  considered an independent subproject.
- All code that is not part of any subproject is considered glue code. Glue code
  is released under the default LICENSE (GPLv3+).

* Subproject LICENSE Declaration Rules
1. If a subproject is originally created by or fully owned by the maintainer and
   does not contain a =LICENSE*= file, it is released under the default LICENSE.
2. If a subproject does not satisfy Rule 2 and lacks the aforementioned LICENSE
   declaration file, then:
   - The subproject may lack a valid LICENSE; all rights are reserved by default.
   - This repository does not automatically grant any LICENSE for it.
   - Such a subproject should be considered “LICENSE unknown”; do not use or 
     distribute it, and contact the original copyright holder.
   - This is likely a mistake; please contact the maintainer for removal as soon
     as possible.
3. All forked/imported third-party subprojects must retain their original
   LICENSE, COPYING, NOTICE, and copyright notice files intact; their content
   must not be deleted or modified.  If a subproject’s top-level directory lacks
   a file matching the Rule 1 pattern, one of the following methods may be used
   to create exactly one such file whose content accurately reflects the
   original LICENSE:
   - Create a note file that explicitly points to the real original LICENSE file 
     (e.g., an org file containing text like):
     #+begin_src org
       This project follows [[file:path/to/LICENSE][LICENSE]].
     #+end_src
   - Rename a file such as COPYING to LICENSE (or to any filename matching the 
     Rule 1 pattern).
   - Create a LICENSE file whose content is equivalent to the original LICENSE 
     file (e.g., by copying the full text).
   - Create a symbolic link named LICENSE that points to the original LICENSE file.
   If the subproject already contains a file matching the Rule 1 pattern, no 
   additional action is required.
4. If a subproject’s top-level directory contains a file matching the pattern
   =LICENSE*= (case-insensitive), the subproject’s LICENSE is determined by that
   file. In the event of a conflict between that file and this root-level
   licensing statement, the subproject’s file takes precedence.
